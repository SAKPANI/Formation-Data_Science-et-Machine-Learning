# Formation en Data Science et Machine Learning

## 🎓 À propos de cette formation

Ce dépôt regroupe mes travaux pratiques, exercices et expérimentations réalisés dans le cadre de mon apprentissage en **Data Science et Machine Learning**.

Mon objectif est de développer progressivement mes compétences dans la manipulation, l'analyse et la visualisation des données, ainsi que dans la conception et l'évaluation de modèles de Machine Learning avec Python et ses bibliothèques spécialisées.

📚 **Ce dépôt est un espace d'apprentissage évolutif : je continue à apprendre, à pratiquer et à enrichir régulièrement mes connaissances à travers de nouveaux exercices et projets.**

*Learning by doing — chaque expérience est une occasion de progresser.* 🚀
