# 🩺 Diabetes — API de prédiction

Ce projet a été réalisé dans le cadre de mon apprentissage de la **Data Science, du Machine Learning et de la conception d'API**.

J'ai suivi une formation de **Ahouahounko Télesphore Guidjime Adinsi**, Data Scientist, Statistician et AI/ML Engineer, à travers sa chaîne YouTube **Data Science En Entreprise**.

📺 [Data Science En Entreprise](https://www.youtube.com/@datascienceenentreprise)

## 🎓 Parcours d'apprentissage

En suivant cette formation, j'ai reproduit et compris progressivement les différentes étapes permettant de passer d'un **modèle de Machine Learning** à une **API exploitable**.

Le projet de formation utilise un modèle de **prédiction du diabète** comme exemple pratique.

Mon travail a consisté à suivre les différentes étapes de la formation en codant progressivement jusqu'à la conception de l'API.

### Ce que j'ai appris

* 🐍 Utilisation de **Python** pour construire le projet
* 📊 Préparation et analyse des données
* 🤖 Conception et entraînement d'un **modèle de Machine Learning**
* 💾 Sauvegarde et chargement d'un modèle (`.pkl`, `.joblib`, etc.)
* ⚡ Création d'une API avec **FastAPI**
* 🔗 Exposition d'un modèle ML à travers une API
* 📥 Réception des données envoyées à l'API
* 🔮 Utilisation de l'API pour effectuer des prédictions
* 🏗️ Organisation d'un projet Data Science destiné à être utilisé comme service
* 🚀 Introduction au **déploiement et à la mise en production**

## 🎯 Objectif

L'objectif de cet apprentissage est de comprendre le processus complet :

```text
Données
   ↓
Préparation des données
   ↓
Modèle de Machine Learning
   ↓
Entraînement
   ↓
Sauvegarde du modèle
   ↓
FastAPI
   ↓
API de prédiction
   ↓
Mise en production
```

Ce projet constitue donc une étape de mon parcours pour apprendre à **transformer un modèle de Data Science / Machine Learning en une API utilisable par d'autres applications**.
